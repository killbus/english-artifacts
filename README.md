# English Artifact Lab

Product research and validation repository for PDF-first digital products.

This is the upstream product layer. It records problems, research, theory,
hypotheses, experiments, product specifications, Team C handoffs, and decisions.
PDF rendering belongs downstream to `handbook-pdf`.

## Core loop

```text
Problem
  ↓
Research
  ↓
Theory
  ↓
Product Hypothesis
  ↓
Content Experiment
  ↓
Purchase / Usage Evidence
  ↓
Product Iteration
  ↓
Team C Handoff
  ↓
handbook-pdf
```

## Product principle

A PDF is not valuable merely because it contains information.

We are exploring artifacts that can guide behavior, accumulate user input,
create return / echo paths, and gain meaning through repeated use.

## Repository map

- `strategy/` — north star, business model, boundaries
- `research/` — audience, problem bank, benchmark, theory, sources
- `experiments/` — experiments and results
- `products/` — hypotheses, specs, retired products
- `handoffs/C/` — implementation contracts for Team C
- `decisions/` — decision log
- `metrics/` — measurement definitions
- `evidence/` — source evidence and provenance
