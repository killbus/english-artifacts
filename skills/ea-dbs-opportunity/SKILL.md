# EA DBS Opportunity

## Goal

Identify whether a real problem deserves a PDF-shaped product and what must be validated next.

## Inputs

- problem-bank entries
- benchmark evidence
- user language
- existing workarounds
- theory notes when relevant
- constraints from `strategy/product-boundary.md`

## Required process

1. Restate the observed problem without inflating it.
2. Separate observed facts from interpretation.
3. Identify the trigger and user job.
4. Test whether a persistent or writable artifact has a real advantage over chat, search, web, video, or a plain document.
5. Identify whether user-generated material can accumulate or return later.
6. Define one falsifiable product hypothesis.
7. Define one smallest useful validation experiment.
8. Define a kill condition.

## Output

Produce or update:

- `research/artifact-opportunity.md`
- a candidate opportunity record
- one product hypothesis under `products/hypotheses/`
- one experiment definition under `experiments/`

## Anti-patterns

Do not:

- start by choosing a PDF format
- make a generic workbook from a broad topic
- convert a theory into a product without a user problem
- equate engagement with purchase intent
- use price as proof of value
