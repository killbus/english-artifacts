# Echo Contract

Static PDF cannot dynamically remember the user.

Echo must therefore be encoded into page structure.

## Requirement

Every important user input should have a future return path.

Possible mechanisms:

- cross-page reference
- personal ID
- previous-version recall
- state change
- comparison
- reuse
- archive / retirement

## Validation questions

1. What input does the user create here?
2. Where does it return?
3. What new action happens when it returns?
4. How can the user see change?

If an important input never returns, question whether the field needs to exist.
