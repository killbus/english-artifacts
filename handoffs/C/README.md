# Team C Handoff

Team C is the implementation team.

## C owns

- handbook-pdf implementation
- Typst / code
- reusable components
- build
- QA
- previews
- technical reporting

## C does NOT own

- audience definition
- problem definition
- pricing strategy
- product positioning
- core user behavior
- product scope expansion

## Handoff order

```text
Product Intent
  ↓
Behavioral Constraints
  ↓
Echo Contract
  ↓
Information Architecture
  ↓
Technical Requirements
  ↓
QA
```

Technical convenience must not silently change product behavior.
