# Suggested DBS Routing

| Stage | Primary DBS capability | Repository output |
|---|---|---|
| Unclear next step | `/dbs` | routing decision |
| Clarify objective / concept | `/dbs-goal`, `/dbs-deconstruct`, `/dbs-good-question` | sharper question / goal |
| Diagnose business opportunity | `/dbs-diagnosis` | diagnosis + next test |
| Study comparable products | `/dbs-benchmark` | benchmark records |
| Ground a claim | `/dbs-theory-grounding` | theory + evidence + boundaries |
| Find a publishable framing | `/dbs-content`, `/dbs-hook`, `/dbs-xhs-title` | content experiment |
| Check resonance / spread | `/dbs-resonate`, `/dbs-spread` | content iteration |
| Record the learning | `/dbs-decision`, `/dbs-save` | durable decision record |

## Rule

Run only the smallest Skill set needed for the current uncertainty. Do not build a ritualized multi-Skill pipeline when one Skill is enough.
