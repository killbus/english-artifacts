# How to use this repository

## Before proposing a product

1. Add the problem to `research/problem-bank.md`.
2. Record relevant benchmarks in `research/benchmark.md`.
3. Record supporting and opposing theory in `research/theory.md`.
4. Add the belief that still needs proof to `ASSUMPTIONS.md`.
5. Convert it into a falsifiable entry in `HYPOTHESIS_REGISTER.md`.

## Before building

Create:

- `products/hypotheses/Hxxx-*.md`
- then `products/specs/Pxxx-*.md` only after evidence is sufficient.

## Before Team C

Create a handoff that contains:

- product intent;
- behavioral constraints;
- Echo Contract;
- page-level user jobs;
- technical requirements;
- QA requirements.

## After an experiment

Record:

1. raw metrics;
2. qualitative observations;
3. learning;
4. decision.

Do not overwrite the original hypothesis.
