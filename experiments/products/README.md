# Product Experiments

Use this area for experiments that connect a content test to a product hypothesis.

Suggested flow:

```text
Problem → Content framing → Product promise → Purchase test → Usage test → Decision
```

This directory defines product-specific experiment setups.

Store:

- the hypothesis being tested;
- the content/product framing;
- the intended purchase or usage test;
- the variables being controlled;
- the expected evidence.

Do not store final experiment results here. Put observed results in
`../results/`.

Do not publish a product merely because a content post performs well.

## Result handoff

Each completed experiment should produce one result record in
`../results/`, referencing the product hypothesis and experiment definition.
