# Experiment Results

Store one result file per experiment.

This directory contains observed outcomes, not experiment designs.

Example:

```text
001-first-xhs-test-result.md
002-price-test-result.md
003-artifact-variant-result.md
```

Record both positive and negative evidence.

Experiment definitions belong in `../products/` when they are specifically
product-linked. General content experiments may remain elsewhere under
`experiments/`.

Each result should point back to the hypothesis and experiment setup it tests,
and forward to the relevant learning and decision records.
