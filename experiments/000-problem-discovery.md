# Experiment 000 — Problem Discovery

## Objective

Find a real, repeated English-related problem that is concrete enough to
become a PDF product.

## Hypothesis

A strong candidate has:

- recurring occurrence
- meaningful friction
- identifiable users
- an existing workaround
- plausible PDF-shaped intervention

## Evidence

Collect:

- comments
- direct user questions
- search behavior
- existing paid products
- purchase reasons
- repeated user language

## Decision rule

Do not create the product until the problem has enough evidence.
