# English Artifacts — Reconciled Strategy + Opportunity Supplement

This archive is an additive / reconciled overlay for the `english-artifacts` repository.

It preserves the previously established product-strategy substrate while integrating
the newer artifact-opportunity and DBS decision layers.

## Install

Copy the contents of this archive into the `english-artifacts` repository root.

Review the files before committing. Existing validated project content should not be
removed merely because a new layer is being added.

## Layers preserved / added

### Existing strategy substrate

- assumptions: what we believe but have not proved
- hypotheses: what can be falsified
- artifact principles: the product constitution
- content <-> product mapping: how distribution relates to commerce
- Team C protocol: hard implementation boundaries
- Echo Contract: static-PDF interaction model
- learnings: what experiments changed in our understanding
- reusable templates: product hypothesis, product spec, experiment result

### New opportunity / DBS layers

- artifact opportunity assessment
- opportunity matrix
- product hypothesis template
- product experiment workspace
- DBS opportunity skill
- DBS diagnosis skill
- DBS role and routing documentation

## DBS position

DBS is a reasoning, routing, diagnosis, and experiment-selection layer.
It is not the product methodology itself and it is not the product truth source.

Use DBS to improve judgment under uncertainty:

```text
DBS
  -> research / diagnosis / theory grounding / experiment choice
  -> english-artifacts product truth
```

The final product decisions, hypotheses, experiments, specifications, and
implementation handoffs belong to `english-artifacts`.

## Integration rule

Prefer additive changes.

Do not replace an existing constraint, responsibility, or decision rule merely
because a newer document expresses a more specific version of it. Merge the
semantics and define a clear source of truth when two files overlap.
