# english-artifacts supplement

This archive contains the additional product-strategy “substrate” discussed for the `english-artifacts` repository.

## Install

Copy the contents of this archive into the repository root.

The files are designed to be additive. They do not replace existing product research.

## Added layers

- assumptions: what we believe but have not proved;
- hypotheses: what can be falsified;
- artifact principles: the product constitution;
- content ↔ product mapping: how distribution relates to commerce;
- Team C protocol: hard boundaries for implementation;
- Echo Contract: static-PDF interaction model;
- learnings: what experiments changed in our understanding;
- reusable templates: product hypothesis, product spec, experiment result.

## Important

These documents deliberately avoid locking the project into one English product format.
They are upstream constraints for experimentation and production.
