# Product Hypotheses

Product ideas belong here before they become product specifications.

## Template

```markdown
# H001 — [Product hypothesis]

## User
[specific user]

## Problem
[specific problem]

## Existing workaround
[what they do today]

## Product hypothesis
[what artifact might help]

## Why PDF
[why static / printable / persistent is useful]

## Expected behavior
[what the user will do]

## Validation
[what evidence would support or reject it]

## Status
proposed
```
