# Artifact Opportunity Framework

Use this before creating a PDF product.

## Purpose

Find a problem that is concrete enough to justify an artifact and distinctive enough to justify a product.

## Opportunity record

```text
Opportunity ID:

User:

Situation / trigger:

Observed problem in user language:

Frequency:

Pain / consequence:

Current workaround:

Why current workaround is insufficient:

Why this should be solved now:

Why a PDF / paper-like artifact could be better:

Expected user behavior:

Potential return / echo mechanism:

Evidence already available:

Main uncertainty:

Falsifier:

Candidate content hook:

Price hypothesis:

Status:
```

## Decision test

A candidate should be rejected or held when the problem is only interesting, but not sufficiently frequent, painful, specific, or productizable.

Do not start with an artifact format and backfill a problem.
