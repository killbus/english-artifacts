# Evidence Synthesis

## Problem clusters

Group repeated problems by underlying job, not by superficial wording.

## Benchmark clusters

Group existing artifacts by the job they perform.

## Questions

1. Which problems repeat across independent sources?
2. Which problems already cause users to spend time, money, or attention?
3. Which existing artifacts appear to solve them?
4. What remains unsolved?
5. Where does a static artifact have an advantage over chat, web, or video?
6. Where could user-generated content return or accumulate?

## DBS handoff

Only after evidence is collected, route promising clusters into DBS
opportunity / diagnosis work.
