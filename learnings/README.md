# Learnings

A learning is not the same thing as an observation or a decision.

Use this area to record what an experiment changed in our understanding.

## Template

```markdown
# L001 — [Learning]

## Observation
[What actually happened]

## Interpretation
[What we currently think it means]

## Confidence
Low / Medium / High

## Implication
[What should change]

## What could prove us wrong
[Evidence that would overturn this learning]
```

Keep failed assumptions and uncomfortable evidence.
